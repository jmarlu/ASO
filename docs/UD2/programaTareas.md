# Introducción a la programación de tareas

En UD2 aprendemos a reconocer y administrar procesos y servicios. Un planificador permite que el sistema lance una orden en un momento determinado, sin que una persona tenga que ejecutarla manualmente.

En GNU/Linux usaremos cron para tareas periódicas, at para una ejecución puntual y systemd timers para tareas integradas con los servicios y sus registros.

Windows queda como ampliación opcional: el Programador de tareas permite definir cuenta, desencadenador y acción. La práctica principal y evaluable de UD5 se realiza en GNU/Linux.
